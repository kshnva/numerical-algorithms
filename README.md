# Numerical Algorithms

Homework assignments for the Numerical Algorithms (Scientific Computing) course at the University of Amsterdam. Each assignment implements and analyses core numerical methods in Python, with derivations and discussion in accompanying PDF reports.

## Assignments

### Assignment 1 -- Numerical Foundations
- Floating-point arithmetic and error analysis
- Relative and absolute error bounds
- Efficient NumPy array operations

### Assignment 2 -- Linear Algebra and Signal Reconstruction
- Gram-Schmidt orthogonalisation and complexity analysis
- Signal reconstruction from noisy integral data
- Least-squares methods and regularisation

### Assignment 3 -- Nonlinear Least Squares
- Gauss-Newton method
- Levenberg-Marquardt method with constant damping parameter
- Convergence analysis and stopping criteria

### Assignment 4 -- Numerical Integration
- Composite trapezoid rule
- Romberg integration
- Convergence rates and error estimation
